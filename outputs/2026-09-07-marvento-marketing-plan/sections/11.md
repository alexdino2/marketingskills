## 11. Marketing operations stack

A small team + marketing skills + light tooling should run this like a focused local growth shop — not a 15-person brand org.

### By AARRR stage

| Stage | Skills | Tools now / next |
|---|---|---|
| Acquisition | `ads`, `ad-creative`, `seo-audit`, `ai-seo`, `content-strategy`, `copywriting`, `social-content`, `analytics-tracking` | GTM, GA4, Google Ads, Meta, Search Console · Ahrefs optional |
| Activation | `emails`, `copywriting`, `cro`, `onboarding` (adapted) | ESP (choose), WhatsApp/SMS, Sheet CRM |
| Retention | `emails`, `customer-research` | ESP / WhatsApp templates |
| Referral | `referrals`, `copywriting`, `launch` | PDF kit, Sheet attribution |
| Revenue | `pricing`, `analytics-tracking` | Occupancy/CAC Sheet |
| Cross-cutting | `product-marketing`, `marketing-ideas`, `marketing-plan` | Notion/Git for this plan |

### Funding / budget unlock mapping

| Tier | Marvento meaning | Stack unlock |
|---|---|---|
| Tier 1 | $0–2K/mo | Organic + partners + nurture only |
| Lean Tier 2 | $2–5K/mo | Search primary; Meta test |
| Tier 2+ | $5–15K/mo | Only if rooms/expansion can absorb demand |

### First hire guidance

When overloaded: **Marketing Manager/Lead** who can run Search + content + partner enablement — not a pure brand hire. Keep strategy in-house; contractors for creative production.
